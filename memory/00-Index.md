# Índice da memória do projeto

Este vault guarda conhecimento global curado para o produto e para agentes de
desenvolvimento. Não é o armazenamento de memória dos tenants do SaaS.

## Regras de curadoria

1. Prefira uma nota pequena por decisão, conceito ou procedimento.
2. Inclua fonte, data e estado; não transforme hipótese em fato aprovado.
3. Atualize ou arquive notas que perderam validade em vez de manter duplicatas.
4. Não copie código, registros de clientes, conteúdo de conversas ou segredos.
5. Se uma informação não puder ser compartilhada com todos os agentes de
   desenvolvimento do repositório, ela não pertence a este vault.
